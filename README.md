# Handoff: 위드북(WithBook) — 책 기반 매칭 SNS 모바일 웹앱

## Overview
위드북은 "책으로 쌓은 취향과 가치관으로 나와 맞는 사람을 만나는" 독서 기반 SNS입니다.
핵심 순서: **독서 기록 SNS가 먼저, 이성 매칭은 그 다음 경험**입니다.
타깃: 책을 좋아하는 20대 후반~30대. 출시 형태: **모바일 웹앱 / PWA** (375~430px 세로 기준, 반응형).

## About the Design Files
이 번들의 파일은 **HTML로 제작된 디자인 레퍼런스(인터랙티브 프로토타입)**입니다. 프로덕션 코드가 아닙니다.
과제는 이 디자인을 **대상 코드베이스의 환경(React/Next.js, Vue 등 — 없다면 PWA에 적합한 프레임워크를 선택)에서 재구현**하는 것입니다.
`WithBook Apple.dc.html`이 원본 소스(마크업 + 상태 로직), `위드북 프로토타입 (공유용).html`은 오프라인에서 바로 열리는 단일 파일 데모입니다. 데모를 브라우저에서 직접 조작하며 동작을 확인하세요.

## Fidelity
**High-fidelity (hifi)** — 색상·타이포·간격·라운딩·인터랙션이 최종 의도입니다. 픽셀 수준으로 재현하되, 코드베이스의 기존 컴포넌트 라이브러리를 활용해 구현하세요.

## Screens / Views (총 11)

### 1. 스플래시
로고 아이콘(64px, #1d1d1f 라운드 18px, 책 SVG 흰/파랑) + "위드북" 44px + 카피 "책을 기록하고, 나누는 곳. / 당신의 서재가 이야기가 되고, / 이야기가 인연이 됩니다" + 풀폭 파란 필 버튼 "시작하기".

### 2. 로그인/회원가입
"반가워요" 28px + 설명. 하단: 이메일 input(11px 라디우스) → "이메일로 계속하기"(파랑) → "또는" 디바이더 → "Apple로 계속하기"(#1d1d1f) → "카카오로 계속하기"(#FEE500) → 약관 동의 캡션.
**구현**: Firebase Auth 또는 Supabase Auth (이메일 + OAuth Apple/Kakao).

### 3. 온보딩 슬라이드 (3장)
중앙 120px 이모지 타일(#f5f5f7) + 타이틀 23px + 설명. 도트 인디케이터(활성 22px 파랑 / 비활성 7px). 순서: ① 나의 서재를 기록하기 ② 독서 피드에서 나누기 ③ 취향이 닿으면, 만남으로. 마지막 버튼 라벨 "책 프로필 만들기".

### 4. 책 프로필 설정
- 인생책 3권: 3열 3/4.2 비율 슬롯, 빈 슬롯은 대시 보더 + "+ 추가", 탭하면 등록/해제
- 인상 깊은 문구: textarea
- 좋아하는 작가(최대 5명) 칩: 선택 시 파랑 배경/흰 텍스트
- 선호 장르 칩(멀티): 선택 시 #1d1d1f 배경/흰 텍스트
- 독서 성향 배지(다크 필): 🔖 밑줄 마니아, 📚 한 달에 2권
- 하단 고정 "완료" 버튼 (마이 탭에서 재진입 시 "저장하기")

### 5. 홈 = 독서 피드 (기본 탭)
헤더 "위드북" + 우측 "＋ 기록" 파란 필 버튼.
- **스토리 행**: 링 두른 60px 원형 아바타 가로 스크롤 (파란 링 #0066cc = 새 독서 스토리, 회색 링 = 확인됨/내 서재)
- 다크 챌린지 배너(#272729): 오버라인 "이달의 공동 독서 챌린지"(#2997ff) + "《싯다르타》 함께 읽기 · D-12"
- "같은 책 읽는 사람들" 가로 스크롤 카드(118px, 표지 3/2 + 제목 + n명 읽는 중)
- **리뷰 포스트 카드 (인스타그램형)**: 헤더(34px 아바타 + 이름 + 《책》·시간 + ⋯) → 문구 영역(#f5f5f7, 표지 64×88 + 인용문) → 액션 행(♡ 💬 ↗ 🔖) → "좋아요 n개" + 작성자 캡션
- **더블탭 좋아요**: 문구 영역 더블탭 시 하트 버스트 애니메이션 + 좋아요, ♡ 버튼 토글 시 파랑(#0066cc) 하트 + 카운트 반영
- 피드 말미 만남 유도 카드: "나와 책 취향이 닿는 사람이 오늘 3명 있어요" + "만남 탭에서 확인하기" 버튼 → 만남 탭 이동

### 6. 새 독서 기록 (글쓰기)
뒤로가기 + "새 독서 기록". 책 검색 input → 결과 리스트(표지 38×52 + 제목/저자, 선택 시 파란 보더 + ✓) → 문구 textarea → 한 줄 감상 input → 하단 "게시하기".
**구현**: 책 검색은 알라딘/네이버 도서 API. 게시물은 DB에 저장 후 피드 최상단 반영(프로토타입은 로컬 상태로 시뮬레이션).

### 7. 만남 = AI 매칭 (2번째 탭)
헤더 "만남" + 레이아웃 스위처(카드/리스트/매거진 세그먼트, 활성 #1d1d1f 필).
- **카드**: 3/3.9 카드 — 상단 프로필 일러스트 + "유사도 n%" 배지(흰 85% 필), 하단 이름·나이 21px + 직업·거리. 하단 액션: ✕(52px 흰 원형 보더) / ♥(파랑) / 카드 탭 → 상세. 좋아요/패스 시 다음 카드.
- **리스트**: 56px 사각(11px) 아바타 + 이름/직업 + 유사도.
- **매거진**: 2열 그리드 3/4 카드.
소진 시 엠프티 스테이트.

### 8. 매칭 상세
76px 원형 아바타 + 이름·나이 + 직업·거리 + 다크 필 "가치관 유사도 n%".
섹션: 인생책 3권(3열) → 인상 깊은 문구 카드 → 최근 읽은 책 → "이런 점이 비슷해요" 체크리스트(✓ 파랑) → **AI 매칭 분석 카드**(겹치는 장르/좋아하는 작가/문구 감성 유사도 3개 프로그레스 바, 6px 트랙 rgba(29,29,31,0.08), 필 #0066cc) → AI 대화 시작 카드(#f5f5f7).
하단: ✕ + "대화 시작하기"(파랑, 채팅으로 이동).
**구현**: 유사도 = 장르/작가/문구 임베딩 기반 스코어(백엔드).

### 9. 채팅
목록: 50px 아바타 + 이름 + 마지막 메시지(ellipsis) + 시간, 행 간 헤어라인.
대화: 상단 고정 "📌 대화 시작 카드"(#f5f5f7, 11px 라디우스) + 말풍선(내 것 #0066cc/흰 텍스트, 상대 흰 배경/보더, max-width 74%, 18px 라디우스) + 입력줄(💛 오프라인 제안 버튼 + input 필 + ↑ 파란 원형 40px).
**동작**: 전송 후 상대 "입력 중" 3도트 인디케이터 → ~1.5초 후 답장 (실서비스: WebSocket/Firestore 실시간 리스너).

### 10. 참가 (오프라인 행사, 3번째 탭)

### 11. 오프라인 신청 & 마이 서재

- 마이: 72px 아바타 + "책 프로필 수정" 보더 필 버튼 + 인생책 3권 + 인상 깊은 문구 카드 + 독서 기록 타임라인

## Interactions & Behavior
- 네비게이션: 하단 5탭 — 홈(📚)/만남(✨)/참가(🗓️)/채팅(💬)/마이(📕). 활성 탭 #0066cc + 라벨, 비활성 opacity 0.4
- 서브뷰(매칭 상세, 채팅방, 글쓰기, 신청)는 탭바를 유지한 채 푸시되는 풀스크린; 뒤로가기는 34px 원형 ‹ 버튼
- 애니메이션: 서브뷰 진입 wbSlideUp(0.38s cubic-bezier(0.32,0.72,0,1), 26px 아래→위 + 페이드), 탭 전환 wbFade(0.32s), 더블탭 하트 wbHeartBurst(0.8s), 온보딩 wbFade/wbPop
- 전역: 모든 버튼 press 시 scale(0.95) 피드백(0.18s), 스크롤 컨테이너 scroll-behavior: smooth
- 상태 유지: 온보딩 완료 여부, 좋아요/패스 이력은 세션 간 유지 (localStorage 또는 서버)

## State Management (프로토타입 기준 → 서버 매핑)
- `route`: splash → login → slides → booksetup → main
- `tab` + `subview` (matchDetail / chatDetail / compose / offline / bookEdit)
- 매칭: `likedMatchIds`, `passedMatchIds` → 매칭 이벤트 테이블
- 피드: `userPosts` (작성 게시물), `likedPosts` (좋아요 토글) → posts/likes 컬렉션
- 채팅: `chatDraftSent` per thread → 실시간 메시지 컬렉션
- 프로필: `mySlots`(인생책), `selectedGenres`, `selectedAuthors`, `quoteDraft`

## Backend Requirements
- **Auth**: 이메일 + Apple/Kakao OAuth (Firebase/Supabase)
- **DB**: users(책 프로필·장르·작가·문구), posts, matches, chats, events
- **실시간 채팅**: Firestore listener 또는 WebSocket
- **AI 매칭**: 장르 교집합 + 작가 교집합 + 문구 텍스트 임베딩 유사도 → 백분율. 상세 화면의 3개 바(장르/작가/문구)로 노출
- **도서 데이터**: 알라딘 or 네이버 책 검색 API (표지·제목·저자)
- **하트페이지 연동**: 행사 일정 조회 + 신청 폼 전달 (제휴 API 협의 필요)
