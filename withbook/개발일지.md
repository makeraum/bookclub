## 2026-08-09

### 던바 구조(L1~L4) 구현
- **왜**: 전략서 ver.2의 핵심인 "독서모임은 본래 던바 구조를 강제받는 포맷"을 제품에 명시하기 위해
- **무엇**: 4계층 커뮤니티 구조 구현
  - L1 밑줄 짝 (2명) — 1:1 매칭, 스트릭 카운터
  - L2 서재 (12~15명) — 서재지기, 월 1회 오프라인
  - L3 책방 (40~60명) — 서재 묶음, 분기 모임
  - L4 도시 커뮤니티 (150명) — 기수 체계
- 탭 구조를 "온라인" → "서재"로 변경. 성별/매칭/좋아요 요소 배제

### AI 3원칙 브랜드 선언
- **왜**: "점수·순위 없이 사람이 확인한다"는 원칙을 UI에 명시해야 신뢰가 생기므로
- **무엇**: 밑줄 짝 매칭에 문장 기반 이유 표시, "알고리즘이 고르고, 사람이 확인합니다" 문구 추가, 마이 탭에 AI 3원칙 카드 추가

### 자료실(슈퍼샘플) 구현
- **왜**: 전략 5장 — 서재 키트를 통째로 공개하여 진입장벽을 낮추고 표준이 되기 위해
- **무엇**: 로그인 없이 접근 가능한 자료실 6종 (진행표, 발제 질문 200선, 실패 패턴, 스타터 키트, 운영 숫자, 책 선정 기준)

- **무엇**: 북 라운지만 파란 배경, 나머지는 연회색+잉크 텍스트로 통일. 임의 색상(갈색, 보라, 초록) 전부 제거

- **무엇**: SVG 파비콘, PWA 아이콘(192/512px), apple-touch-icon 생성. 앱 타이틀 "WithBook — 책으로 만나는 기록"으로 변경

### 주최자 프로필 카드 강화
- **왜**: 기존 주최자 섹션이 이름+회색 아이콘뿐이라 "이 사람 누구지? 진행은 잘할까?" 하는 의문이 남았으므로. AI가 주최자의 실제 기록에서 근거를 뽑아 신뢰를 만들어주는 카드로 교체
- **무엇**:
  - HostProfileCard 공유 컴포넌트 (모임 상세 + 서재 상세 재사용)
  - AI 소개문 3~4문장 (밑줄·읽은 책·작가 기반, LLM 연동 지점 주석 표시)
  - 조개 기반 검증 지표: 밑줄·완독·모임·발제·붙듦 (숫자만, 점수/순위 없음)
  - 대표 밑줄 인용 카드 + "이 책에 이미 밑줄 n개를 남겼습니다"
  - 기록 부족 시 "아직 기록이 쌓이는 중" 담백 표시
  - 소개문 비공개 토글 + "이 소개는 주최자가 남긴 기록을 바탕으로 정리되었습니다" 고지
  - 데모 주최자 5명 (이서연·한소율·오지환·김하늘·정우진) 프로필 데이터

### 비공개 테스트 준비 — 피드백·에러·안내 강화
- **왜**: 비공개 테스트 배포 전, 테스터가 의견을 남기고, 오류 시 흰 화면을 보지 않으며, 테스트 맥락을 이해할 수 있어야 하므로
- **무엇**:
  - 피드백 플로팅 버튼: 모든 메인 화면 우측 하단에 상시 노출. 탭하면 바텀시트로 의견 입력 → Supabase `feedback` 테이블에 저장 (화면 이름·시간·UA 자동 기록)
  - 에러 바운더리: React ErrorBoundary로 앱 전체 감싸기. 오류 발생 시 "문제가 생겼어요" + 다시 시도 / 새로고침 버튼 표시
  - 첫 진입 안내: 처음 접속 시 "지금은 비공개 테스트예요. 예시 데이터가 섞여 있습니다" 모달 1회 표시 (localStorage 기반)
  - 빈 화면 안내 보완: 홈 피드에 밑줄 0개일 때 "아직 밑줄이 없어요" + 첫 밑줄 남기기 버튼 추가
  - Supabase 스키마: `supabase-feedback.sql` 추가 (feedback 테이블 + RLS 정책)

### 서재지기 콘솔 추가
- **왜**: 서재지기가 모임을 운영할 때 필요한 도구(출석 관리, 발제 질문, 멤버 현황)가 없으면 앱 밖에서 별도 관리해야 하므로. AI 3원칙(점수·순위·퍼센트 금지)을 준수하는 운영 화면 제공
- **무엇**:
  - 진입점 2곳: 마이 탭 "서재지기 콘솔" 카드 (주최 서재 1개 이상일 때), 서재 상세 "운영" 버튼 (서재지기만)
  - 콘솔 5개 탭:
    - 출석 체크: 멤버 목록 토글 → attendances 테이블 기록, co_attendances 자동 증가
    - 발제 질문: 장르(소설/비문학/에세이/자기서사) 기반 8개 자동 추출 (자료실 200선에서), LLM 연동 지점 주석. 다시 뽑기 + 사용 표시
    - 노쇼 현황: 누적 2회 이상 불참자만 표시, 서재지기에게만 보임. 멤버 화면에 노출 안 됨
    - 조용한 회원: 3주 이상 기록 없는 멤버, "n주째 기록이 없어요" 사실만 표시 (점수/퍼센트/순위 없음)
    - 모임 메모: 서재지기 전용 자유 메모
  - Supabase 스키마: `supabase-console.sql` (attendances, co_attendances, session_notes, discussion_questions + RLS)
  - 체험 계정에서 sj1(강남 화요 서재) 소유자로 설정하여 콘솔 체험 가능
